# 🚗 AI Smart City Driving Simulator

### Detect • Think • Decide • Drive

An interactive browser-based **AI Smart City Driving Simulator** developed using **HTML, CSS, and JavaScript**.

The project simulates a smart-city driving environment where the player can manually control a car or switch to an **AI driving mode**. The AI analyzes traffic conditions, traffic lights, obstacles, speed, and destination to make driving decisions.

---

## 🌆 Project Overview

The **AI Smart City Driving Simulator** is designed to demonstrate how artificial intelligence and intelligent decision-making can be applied to autonomous driving.

The simulator provides a city-like environment with:

- 🛣️ Multiple roads
- 🚦 Traffic signals
- 🚘 Moving traffic vehicles
- 🤖 AI driving mode
- 🎮 Manual driving mode
- 🗺️ Mini-map
- ⚡ Multiple speed levels
- 💥 Collision detection
- 🏁 Destination system
- 📊 Speed and score monitoring
- 🧠 AI decision display

The project runs directly in a modern web browser and does not require a backend server.

---

# ✨ Features

## 🎮 Manual Driving

The player can manually control the car using keyboard controls.

### Controls

| Key | Action |
|-----|--------|
| `W` / `↑` | Accelerate |
| `S` / `↓` | Reverse / Brake |
| `A` / `←` | Turn Left |
| `D` / `→` | Turn Right |
| `SPACE` | Emergency Brake |
| `M` | Toggle AI Mode |
| `R` | Reset Game |

---

## 🤖 AI Driving Mode

The simulator includes an AI driving system that automatically controls the vehicle.

The AI can:

- Detect the destination
- Calculate the direction toward the destination
- Detect dangerous situations
- Detect red traffic lights
- Reduce speed when necessary
- Decide when to accelerate
- Navigate toward the destination

The AI displays its current decision in the dashboard.
